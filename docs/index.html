LunaCode

Um app desktop para conversar com o Claude Code, o Codex e outros agentes de código numa interface só. O app não é um modelo de IA: ele usa as CLIs oficiais que você já tem instaladas e o login que você já fez nelas.

Baixar para Windows Ver código no GitHub

Instalador para Windows 10 (1809+) e Windows 11. macOS e Linux não são suportados por enquanto.

O que ele faz

Tudo numa janela só, com o que o agente faz ao lado da conversa.

Conversa

  • Respostas em tempo real
  • Anexos de imagem e de arquivo
  • Menu / com comandos, skills e comandos das CLIs
  • Planejamento com plano completo no painel
  • Compactação de contexto

Projeto e git

  • Conversa com pasta de projeto ou sem pasta
  • Worktrees: trabalhar numa branch sem mexer na pasta atual
  • Painel de alterações com diff e desfazer

Painel lateral

  • Plano e progresso das tarefas
  • Árvore de arquivos com editor no lugar do chat
  • Terminal na pasta do projeto
  • Navegador com abas e favoritos

Extensões

  • Skills e servidores MCP, do catálogo ou por URL
  • Plugins que acrescentam painéis, comandos e avisos
  • Segredos de MCP ficam nas variáveis do seu usuário

Visual

  • Temas claros e noturnos
  • Tema próprio, com editor e formatos de componente
  • Efeito de vidro opcional
  • Interface em português, inglês e outros idiomas

Atualização

  • Atualização pelo próprio app, em Configurações > Sobre
  • Antes de instalar, encerra execuções em andamento

Agentes

Você escolhe o motor de cada conversa, e pode montar um orquestrador para dividir os papéis.

CLIs instaladas no seu computador

Claude Code Codex OpenCode Cline GitHub Copilot Hermes Antigravity

Perfis de API

Provedores como OpenRouter e DeepSeek, com a chave guardada no cofre do sistema.

Orquestrador

Cada papel (planejar, executar, conversar e subagentes) pode usar um agente e um modelo diferentes.

Como funciona

Uma casca em volta das ferramentas que você já usa.

  1. Instale e faça login em pelo menos uma CLI, como claude ou codex.
  2. Abra o LunaCode e escolha a pasta do projeto, ou trabalhe sem pasta.
  3. Converse com o agente. O plano, as alterações, o progresso e o terminal aparecem ao lado.
  4. Instale skills, MCP e plugins uma vez e use nas CLIs.
